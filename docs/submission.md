# Hackathon Submission Details

**Name:** Rio — Smart Event Vendor Matching

**Challenge:** Smart Vendor Matching (#79-lite).

**Repository:** https://github.com/BAITC-Hacks/hack-009717fe-rio

**Команда:** Темирлан Досмухамбетов (frontend/UI), Мирас Ринатулы (backend/API), Айназ Абитай (данные, аудит и документация).

**Description:** Rio helps event customers choose up to three vendors from a 200-profile catalog using city, date, event format, category and budget. Optional language, duration and free-text preferences are supported. Unavailable vendors are excluded, and each card includes a concrete explanation and a quotation from the profile. The service distinguishes a missing category from candidates failing the constraints, explains short lists and shows calendar-related changes between dates. The original 66 organizer profiles are preserved; synthetic additions are clearly labelled and retained with a separate audit artifact. The implementation includes deterministic lexical ranking, six demo scenarios, a responsive Russian-language interface and automated checks. Stack: Python standard library, HTML, CSS and JavaScript. Start with `python app.py`, then open http://127.0.0.1:8000. Development was assisted by the Codex AI agent; no external AI API or keys are required to run the application.

**Deployed version:** no public deployment; local startup is documented in the README.
