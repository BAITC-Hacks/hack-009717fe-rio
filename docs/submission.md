# Данные для сдачи проекта

**Название:** Rio — умный подбор event-подрядчиков

**Кейс:** Smart Vendor Matching (#79-lite)

**Репозиторий:** https://github.com/BAITC-Hacks/hack-009717fe-rio

**Команда:** Темирлан Досмухамбетов (frontend/UI), Мирас Ринатулы (backend/API), Айназ Абитай (данные, аудит и документация).

## Описание для платформы

Rio помогает заказчику выбрать до трёх подрядчиков из каталога по городу, дате, формату мероприятия, категории и бюджету. Дополнительно учитываются язык, длительность и свободные текстовые пожелания. Занятые профили исключаются, а каждая карточка содержит конкретное объяснение и цитату из описания.

Сервис различает отсутствие категории в городе и ситуацию, когда кандидаты есть, но не проходят ограничения. Он объясняет короткую выдачу, показывает изменение результатов между датами и использует детерминированное лексическое ранжирование. В runtime-каталоге 200 профилей; исходные 66 записей сохранены, синтетические добавления помечены и вынесены в отдельный аудит-артефакт.

Стек: Python со стандартной библиотекой, HTML, CSS и JavaScript. Запуск: `python app.py`, затем открыть `http://127.0.0.1:8000`. Внешние AI-ключи не нужны.

## Порядок сдачи

1. Проверить, что актуальная версия проекта находится в командном GitHub-репозитории.
2. Открыть страницу треков и выбрать кейс #79-lite.
3. Нажать «Сдать решение» и вставить название, описание и ссылку на репозиторий.
4. Проверить подтверждение приёма заявки на платформе.

Основной README находится в корне репозитория и написан на русском языке. Подробные роли участников: `docs/participant1-frontend.md`, `docs/participant2-backend.md` и `docs/participant3-data-audit.md`.
