# README Айназ Абитай

## Моя роль в проекте

Я отвечаю за данные, аудит, тестовые сценарии, README, скриншоты и финальную проверку воспроизводимости Rio перед защитой.

## Что я реализовала

- проверку структуры каталога и уникальности ID;
- контроль цен, городов, категорий, форматов, описаний и календарей;
- проверку происхождения исходных и синтетических профилей;
- сценарии редкой категории, смены даты, недостаточного бюджета и отсутствующей категории;
- запуск автоматических тестов и `tools/audit_data.py`;
- документацию команды, чек-листы участников и материалы для жюри;
- фиксацию результатов демо и скриншотов интерфейса;
- проверку того, что одинаковый запрос даёт одинаковый порядок карточек.

## Как работает проверка

1. Проверяется, что у каждого профиля уникальный `id` и положительная цена.
2. Проверяются даты занятости в пределах календаря проекта.
3. Проверяется наличие города, категории, формата и описания.
4. Синтетические профили должны иметь `synthetic=true` и быть видимыми в интерфейсе.
5. Тестируется, что занятые профили не попадают в `cards`.
6. Проверяются состояния `matched`, `no_category` и `no_match`.
7. Повторный запрос сравнивается с первым для проверки детерминированности.

## Как проверить мою работу

Из корня проекта запустить:

```bash
python3 -m unittest discover -s tests -v
python3 tools/audit_data.py --include-synthetic --markdown
```

Ожидаемый результат тестов: `Ran 10 tests` и `OK`. Затем открыть сайт и пройти сценарии 01–06. Отдельно проверить редкую категорию, изменение даты и пустую выдачу.
