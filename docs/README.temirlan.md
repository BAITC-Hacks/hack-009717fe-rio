# README Темирлана Досмухамбетова

## Моя роль в проекте

Я отвечаю за frontend и пользовательский интерфейс Rio. Моя задача — превратить сложную логику подбора в понятный сценарий: пользователь заполняет форму, нажимает одну кнопку и получает короткую подборку с объяснением каждого выбора.

## Что я реализовал

- русскоязычную страницу Rio с фирменным визуальным стилем;
- форму для города, даты, формата, категории, бюджета, длительности, языка и пожеланий;
- адаптивную верстку для ноутбука и телефона;
- загрузку реальных вариантов полей через `GET /api/v1/meta`;
- отправку запросов в `POST /api/v1/recommendations`;
- карточки подрядчиков с ценой, доступностью, языками, часами и цитатой;
- отображение причин выбора, исходного описания и аудита исключений;
- сравнение результатов при смене даты;
- состояния загрузки, ошибки и доступные интерактивные элементы;
- шесть готовых сценариев для проверки интерфейса.

## Как работает один запрос

1. При загрузке frontend получает варианты полей и сценарии через `/api/v1/meta`.
2. Пользователь заполняет форму или выбирает готовый сценарий.
3. Браузер проверяет обязательные поля и отправляет JSON в `/api/v1/recommendations`.
4. Ответ отображается как подбор, отсутствие категории или отсутствие совпадений.
5. Для каждой карточки выводятся цена, факты, объяснение, цитата и подробности профиля.
6. При запросе на другую дату интерфейс показывает, какие прошлые профили стали заняты.

## Как проверить мою работу

Запустить сервер:

```bash
python3 app.py
```

Открыть `http://127.0.0.1:8000` или [опубликованный сайт Rio](https://rio-hackalem-podium.vercel.app/).

Проверить по порядку:

1. Нажать «01 · Осенний корпоратив» и убедиться, что видны три карточки.
2. Раскрыть «Подробнее о профиле и подборе».
3. Нажать «02 · Другая дата» и показать сравнение.
4. Нажать «03 · Редкая категория» и показать короткую выдачу.
5. Нажать «04 · Бюджет не проходит» и показать объяснение `no_match`.
6. Уменьшить окно браузера и проверить мобильную раскладку.
