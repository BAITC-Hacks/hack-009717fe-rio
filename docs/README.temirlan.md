# README Темирлана Досмухамбетова

## Моя роль в проекте

Я отвечаю за frontend и пользовательский интерфейс Rio. Моя задача — превратить сложную логику подбора в понятный сценарий: пользователь заполняет форму, нажимает одну кнопку и видит короткую подборку с объяснением каждого выбора.

## Что я реализовал

- собрал русскоязычную страницу Rio с фирменным визуальным стилем;
- сделал форму запроса для города, даты, формата, категории, бюджета, длительности, языка и пожеланий;
- добавил адаптивную верстку для ноутбука и телефона;
- подключил frontend к `GET /api/meta` для загрузки вариантов полей и демо-сценариев;
- подключил `POST /api/recommend` и обработку успешного, короткого и пустого результата;
- сделал карточки подрядчиков с ценой, городом, языками, доступностью, часами, объяснением и цитатой;
- добавил раскрытие исходного описания и технических деталей подбора;
- добавил аудит исключённых профилей и сравнение результатов при смене даты;
- добавил клавиатурную навигацию, фокус и состояния кнопок для удобства использования;
- оформил шесть готовых сценариев для демонстрации жюри.

## Как работает пользовательский путь

1. При загрузке `app.js` получает метаданные каталога через `/api/meta`.
2. В выпадающие списки подставляются реальные города, категории, форматы и языки.
3. Первый сценарий загружается автоматически, поэтому сайт сразу показывает рабочий результат.
4. При отправке формы frontend проверяет обязательные поля браузером и отправляет JSON в `/api/recommend`.
5. Ответ отображается в одном из трёх состояний: подбор найден, категория отсутствует или условия не подходят.
6. Для каждой карточки выводятся объяснение backend, цитата профиля и дополнительные факты.
7. При повторном запросе с другой датой интерфейс сравнивает предыдущую и новую выдачу.

## Как проверить мою работу

Запустить проект:

```bash
python3 app.py
```

Открыть `http://127.0.0.1:8000` или опубликованную версию [rio-hackalem-live.vercel.app](https://rio-hackalem-live.vercel.app/).

Проверить по порядку:

1. Нажать «01 · Осенний корпоратив» и убедиться, что видны три карточки.
2. Раскрыть «Подробнее о профиле и подборе».
3. Нажать «02 · Другая дата» и показать блок сравнения.
4. Нажать «03 · Редкая категория» и показать короткую выдачу.
5. Нажать «04 · Бюджет не проходит» и показать объяснение `no_match`.
6. Уменьшить окно браузера и проверить мобильную раскладку.

## API-контракт, который я использую

Frontend ожидает от backend поля `status`, `message`, `cards`, `rejected`, `exclusion_counts`, `pool_count`, `eligible_count` и `elapsed_ms`. Имена полей и значения русских категорий нельзя менять только на frontend: они являются общим контрактом с `app.py`.

## Что сказать жюри

«Я отвечал за то, чтобы сложный подбор был понятен обычному заказчику. Интерфейс не прячет ограничения: на карточке видны цена, дата, язык, часы и конкретная причина выбора. Если вариантов мало или нет совсем, Rio показывает это честно и объясняет, какое условие повлияло на результат. Интерфейс использует тот же API, что и тесты, поэтому демонстрационные кнопки не являются заранее записанными ответами».
