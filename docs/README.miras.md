# README Мираса Ринатулы

## Моя роль в проекте

Я отвечаю за backend и алгоритм подбора подрядчиков Rio. Моя задача — сделать так, чтобы рекомендации были корректными, воспроизводимыми и объяснимыми: сервис должен учитывать все обязательные условия и показывать, почему профиль попал или не попал в результат.

## Что я реализовал

- HTTP API на Python без внешних библиотек;
- загрузку runtime-каталога из `data/contractors.csv`;
- endpoint `GET /api/meta` с вариантами полей, статистикой и готовыми сценариями;
- endpoint `POST /api/recommend` для подбора подрядчиков;
- проверку города, даты, формата, категории, бюджета, языка и длительности;
- отдельные исходы `matched`, `no_category` и `no_match`;
- исключение занятых профилей по календарю;
- исключение профилей с ценой выше бюджета или несовместимыми условиями;
- детерминированное ранжирование по совпадению пожеланий, цене и ID;
- объяснения с фактами запроса и цитатой исходного описания;
- аудит причин исключения каждого неподходящего профиля;
- автоматические тесты для граничных случаев и воспроизводимости.

## Как работает один запрос

1. Сервер проверяет формат JSON и обязательные поля.
2. Выбираются профили точного города и категории.
3. Из пула исключаются занятые на дату, слишком дорогие и неподходящие по формату, языку или длительности.
4. Пожелания пользователя разбиваются на основы слов и используются как мягкий сигнал релевантности.
5. Результаты сортируются по текстовому баллу, цене и ID. Случайности нет.
6. Возвращаются максимум три карточки, сообщение, объяснения и аудит исключений.

## Состояния ответа

- `matched` — подходящие профили найдены;
- `no_category` — в выбранном городе нет такой категории;
- `no_match` — категория есть, но условия не позволяют рекомендовать профиль.

Причины исключения могут пересекаться: один профиль одновременно может быть занят и превышать бюджет. Поэтому сумма счётчиков причин иногда больше общего числа исключённых профилей.

## Как проверить мою работу

Запустить сервер:

```bash
python3 app.py
```

Проверить тесты:

```bash
python3 -m unittest discover -s tests -v
```

Проверить метаданные:

```bash
curl http://127.0.0.1:8000/api/meta
```

Проверить подбор:

```bash
curl -X POST http://127.0.0.1:8000/api/recommend \
  -H 'Content-Type: application/json' \
  -d '{"city":"Алматы","date":"2026-10-04","event_format":"корпоратив","category":"Ведущий","budget":1500000,"hours":4,"language":"русский","preferences":"интеллигентный юмор импровизация"}'
```

Ожидаемый результат тестов: `Ran 10 tests` и `OK`. Повтор одинакового запроса должен сохранить тот же порядок карточек.
