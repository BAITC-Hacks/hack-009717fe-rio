# Мирас Ринатулы — backend и алгоритм

Полная персональная документация Мираса находится в [README Мираса](README.miras.md).

## Зона ответственности

Мирас отвечает за API и корректность подбора: валидацию запроса, выбор пула по городу и категории, жёсткие фильтры, детерминированное ранжирование, объяснения и тесты.

## Основные файлы

- `app.py` — HTTP-сервер, загрузка каталога, `/api/meta`, `/api/recommend`, фильтры и ранжирование;
- `tests/test_app.py` — автоматические проверки требований и граничных случаев;
- `data/contractors.csv` — authoritative runtime-каталог.

## Как работает подбор

1. Проверяются обязательные поля, дата, бюджет, часы, формат и язык.
2. Выбираются профили точного города и категории.
3. Исключаются занятые, слишком дорогие, неподходящие по формату, языку или длительности.
4. Оставшиеся профили ранжируются по совпадению пожеланий, затем по цене и ID.
5. Возвращаются максимум три карточки, факты, цитата и аудит исключений.

## Проверка

```bash
python3 -m unittest discover -s tests -v
curl http://127.0.0.1:8000/api/meta
```

Ожидаемый результат тестов — `Ran 10 tests` и `OK`. Алгоритм является объяснимым лексическим baseline; сервис не выдаёт сгенерированные факты и не использует LLM во время работы.
